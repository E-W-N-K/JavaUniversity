# Фитнес-клуб — лабораторные работы № 1–3, вариант 9

Одна консольная программа на Java 21 и Maven. Данные хранятся в памяти до завершения работы.

## Сборка и запуск

Из папки `fitness-club`:

```powershell
mvn clean test
mvn exec:java
```

В меню: `1` — добавить клиента, `2` — выдать абонемент, `3` — активировать, `4` — записать посещение, `5` — список, `0` — выход. Для даты можно нажать Enter и выбрать сегодня.

## Демо для защиты

Создать клиента; создать абонемент с лимитом 8 посещений в месяц; активировать; записать посещение; вывести список. Затем попробовать повторную активацию или дату после окончания срока: программа выведет понятную ошибку и вернётся к меню.

UML-диаграммы находятся в `../diagrams` в формате PlantUML: их можно открыть в любом просмотрщике PlantUML. Разбор кода и ответы для защиты — в `../ИЗУЧИТЬ_КОД.md`. Фактический вывод демонстрационного запуска сохранён в `demo-session.txt`.
